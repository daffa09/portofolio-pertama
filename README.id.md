# Portofolio Pertama Saya (My First Portfolio)

<img width="1905" height="898" alt="image" src="https://github.com/user-attachments/assets/33e78d8e-a3e0-45f5-92d4-70d7669c1627" />

Situs web portofolio pertama saya, yang menunjukkan awal dari perjalanan pengembangan web saya. Dibangun dengan HTML, CSS, dan JavaScript murni, proyek yang sederhana namun bermakna ini mewakili tonggak penting dalam jalur pembelajaran saya.

## 📋 Ringkasan

Ini adalah `daffafathan-portofolio.github.io` - situs web portofolio pertama saya yang dibuat dengan tata letak sederhana namun konten yang bermakna. Proyek ini berfungsi sebagai pengenalan saya terhadap pengembangan web dan presentasi portofolio.

## ✨ Fitur

- **Tata Letak Sederhana**: Desain yang bersih dan mudah dinavigasi.
- **Informasi Pribadi**: Bagian tentang saya.
- **Showcase Proyek**: Menampilkan proyek-proyek awal saya.
- **Bagian Kontak**: Cara untuk menghubungi saya.
- **Desain Responsif**: Berfungsi di berbagai perangkat.
- **Hosting di GitHub Pages**: Hosting statis gratis.

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur halaman.
- **CSS3**: Gaya dan tata letak.
- **JavaScript**: Elemen interaktif.
- **GitHub Pages**: Platform hosting.

## 📁 Struktur Proyek

```
portofolio-pertama/
├── index.html          # Halaman beranda
├── about.html          # Halaman tentang saya
├── projects.html       # Showcase proyek
├── assets/
│   ├── css/
│   │   └── style.css  # Stylesheet utama
│   ├── js/
│   │   └── script.js  # File JavaScript
│   └── img/           # Gambar dan ikon
├── loader.gif          # Animasi pemuatan
└── _config.yml        # Konfigurasi GitHub Pages
```

## 🚀 Memulai

### Melihat Online

Portofolio ini dihosting di GitHub Pages:
[https://daffafathan-portofolio.github.io](https://daffafathan-portofolio.github.io)

### Menjalankan Secara Lokal

1. **Clone Repositori**
   ```bash
   git clone https://github.com/usernameanda/daffafathan-portofolio.github.io.git
   ```

2. **Buka di Browser**
   - Cukup buka file `index.html` di browser Anda.
   - Atau gunakan server lokal (seperti Live Server di VS Code).
